Preguntas frecuentes

¿Necesito tener un software contable?

No es obligatorio. Si no tienes, podemos trabajar con formatos Excel. Pero si tienes Siesa, Siigo, Alegra o Odoo, la integración es automática.

¿Cómo suben mis ventas al software contable?

Extraemos tus ventas del marketplace QRP2P y las cargamos automáticamente a tu software contable a través de API o archivos planos.

¿Se encargan de facturación electrónica?

Sí. Emitimos y enviamos facturas electrónicas a tus clientes, cumpliendo con todos los requisitos de la DIAN.

¿Qué pasa si tengo muchos productos?

No hay problema. Nuestro sistema puede manejar inventarios de miles de referencias y sincronizarlos con tu software contable.

¿Puedo cancelar el servicio cuando quiera?

Sí. El servicio es mes a mes. Cancelas cuando quieras sin penalización.
